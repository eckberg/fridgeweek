# Security

Fridgeweek has no accounts, no database and stores nothing about you. The only server-side
component planned is a PDF renderer that receives a sheet configuration and returns a file.

If you find a vulnerability, please report it privately through GitHub's
"Report a vulnerability" button on the Security tab of this repository rather than in a
public issue. You will get a reply within a week.

Supported versions: the latest commit on `main` and the latest release.
